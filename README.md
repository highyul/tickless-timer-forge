# Tickless Timer

A lightweight, minimal Minecraft timer mod that operates based on system time, completely independent of the in-game tick rate.

---

## 💡 Features
* **Full Tickless Operation:** Even if the game suffers from lag or low TPS, the timer continues to count accurately based on real-world time.
* **Lightweight & Simple:** Focuses purely on system time with zero bloat, ensuring no impact on game performance.

## 🛠️ Requirements
* **Minecraft:** `1.20.1`
* **Mod Loader:** Forge `47.4.10`+

## 📥 Installation
Place the built `.jar` file (or downloaded file) into your `mods` folder.
